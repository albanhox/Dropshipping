# Tuft & Tail — Automated Dropshipping Store

A complete, zero-monthly-cost dropshipping business in a repo: a live-deployable storefront plus the research and step-by-step playbooks to run it.

**The goal:** $100 net profit in week 1 → $1,000/month net.

## What's here

| File | What it is |
|---|---|
| `index.html` + `assets/` | The storefront — static site, deploys free to GitHub Pages/Vercel |
| `products.js` | The product catalog — the only file you edit to run the store |
| `docs/RESEARCH.md` | Why pet accessories, why these 6 products, why this stack (with sources) |
| `docs/SETUP.md` | Deploy the site + connect Stripe checkout (~10 min) |
| `docs/PLAYBOOK.md` | Day-by-day week 1 plan to the first $100 profit |
| `docs/GROWTH.md` | Staged plan to $1k/month: bundles → paid ads → full automation |

## The stack (and why it costs $0/month)

- **Storefront:** static HTML/CSS/JS on GitHub Pages — free
- **Checkout:** Stripe Payment Links — no monthly fee, 2.9% + 30¢ per sale
- **Fulfillment:** CJ Dropshipping free plan, US-warehouse products, 7–12 day delivery
- **Traffic:** organic TikTok/Reels/Shorts + Facebook Marketplace (no ad budget required)

Fixed costs at launch: **$0** (optionally ~$10/yr for a domain later). Compare: Shopify + apps ≈ $50+/month before your first sale.

## Start here

1. Read `docs/SETUP.md` — get the site live and Stripe connected (Day 1).
2. Follow `docs/PLAYBOOK.md` day by day for week 1.
3. When the first sales land, switch to `docs/GROWTH.md`.

## Honest expectations

Read the reality-check section in `docs/RESEARCH.md`. $100 in week 1 is achievable with the two-track approach in the playbook, but organic traffic typically takes 30–60 days to compound — the plan is built around that fact, not around a lottery ticket.
